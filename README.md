To update the writing page after adding a poem, run:

python3 updateScript.py

Short stories can be added as `.docx` files under
`writing/shortStories/<year>/`. The filename becomes the story title, and
the script preserves paragraph indentation and basic text styling when it
generates the preview and full-story page.
